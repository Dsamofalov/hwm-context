# hwm-context

Private derived/materialized read-model repository for the HeroesWM autonomous development infrastructure.

Authoritative project state is not stored here. Contents must be rebuildable from authoritative sources. Ordinary product agents are read-oriented and should not have write access. Generated artifacts must carry source provenance in future milestones.

I01 creates structure only. It does not create current state, generated bootstrap, wiki pages, graph data, claims, or historical handoff imports.
